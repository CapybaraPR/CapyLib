## 📖 О проекте

**CapyLib** — это комплексный фундамент для разработки серверов и плагинов SCP:SL на базе EXILED. Библиотека объединила и развила лучшие наработки **AspectLib**, **Redox-Engine** и **Hazbin.Core**, предоставляя разработчикам богатый инструментарий для управления сетевым кодом, сущностями, базами данных, эффектами и кастомным контентом.

Все компоненты компилируются в единую оптимизированную сборку **`CapyLib.dll`** под `.NET Framework 4.8`.

## 🏛️ Архитектура и функционал

### 1. ⚙️ `Capy.Core` — Фундамент и утилиты

* **Модульная система (`ModuleLoader`, `ModuleManager`)**:
  * Динамический поиск и рефлексивная загрузка модулей с разрешением графа зависимостей через `[DependsOn]`.
  * Полное рантайм-управление: включение (`Enable`), выключение (`Disable`), переключение (`Toggle`) и горячий перезапуск (`Restart`) модулей без рестарта сервера.
* **Мульти-файловый YAML (`ConfigLoader`)**:
  * Изолированные конфиги для каждого модуля по пути `Plugins/CapyLib/Configs/<ModuleName>.yml`.
* **DRM и Лицензирование (`LicenseManager`)**:
  * HTTP-валидация ключей сервера с поддержкой автоматического режима разработчика (`DEV_LICENSE` / `validate_license: false`).
* **Базы данных (`IDatabaseProvider`)**:
  * **LiteDB** — встроенная NoSQL база данных (`Plugins/CapyLib/Database/CapyData.db`).
  * **MongoDB** — высокопроизводительный драйвер для сети распределённых серверов.
* **Шина событий (`EventBus`)**:
  * Потокобезопасная Pub/Sub шина для слабой связанности компонентов.
* **Авто-регистратор событий (`EventRegistrar`)**:
  * Рефлексивная подписка статических методов на любые события EXILED по типам параметров.
* **Движок плейсхолдеров (`PlaceholderReplacer`)**:
  * Поддержка тегов `%player_name%`, `%player_hp%`, `%server_tps%`, `%round_time%` и регистрация кастомных резолверов.
* **Системные Features & Helpers**:
  * `GlobalCooldown` и `PlayerCooldown` — потокобезопасные кулдауны с автоматической очисткой.
  * `PrefabManager` / `PrefabStore` — кэширование и спавн сетевых префабов игры.
  * `GradientHelper` / `HtmlHelper` / `SnowflakesHelper` / `RegexHelper` — генерация градиентного текста, форматирование цвета и строковых шаблонов.
  * `PermittedCommand` — база команд с проверкой прав доступа.
* **Расширенные Enums**:
  * `DamageType`, `DamageUniversalType`, `DamageSubType` — типизация любого урона в игре.
  * `EffectType` — полный реестр статус-эффектов игроков.
  * `CustomInfoColor` — палитра кастомных цветов для никнеймов и ролей.
  * `DoorPermissionCheck` — уровни доступа к дверям комплекса.

### 2. 🪄 `Capy.Engine.FakeSync` — Подмена сетевых данных клиентам

Мощная низкоуровневая система перехвата и подмены пакетов Mirror Networking:
* **`FakeSyncVar`**: Подмена синхронизируемых переменных персонально для выбранных игроков (позиция, роль, здоровье, невидимость).
* **`FakeSyncList`**: Персональная подмена сетевых списков и состояний инвентаря.
* **`FakeRpc`**: Отправка изолированных RPC пакетов конкретным клиентам.
* **`AdminToyFakeExtensions`**: Создание и управление фейковыми примитивами, источниками света и аудио-игрушками персонально для каждого игрока.
* **`MirrorWriterExtensions`**: Быстрая сериализация сетевых буферов Mirror.

---

### 3. 🧩 `Capy.Core.Extensions` — Богатые методы расширения

* **`PlayerExtensions`**: Быстрая проверка живости, установка временных переменных `SessionVariables`, безопасная выдача предметов, получение данных.
* **`NetworkExtensions`**: Отправка персональных пакетов (`SendFakeSyncVar`, `SendFakeRpc`), скрытие игроков от выбранных клиентов.
* **`DamageExtensions`**: Преобразование и детализация урона (оружие, окружение, эффекты, гранаты, падение).
* **`DummyExtensions`**: Создание, кастомизация и управление NPC / Dummies.
* **`ReflectionExtensions`**: Быстрый доступ к приватным полям, свойствам и методам без накладных расходов.
* **`StringExtensions` / `CollectionExtensions` / `DictionaryExtensions`**: Полезные утилиты для повседневной разработки.

---

### 4. 🌐 `Capy.API` — Внешние интеграции и телеметрия

* **`CapyApiClient`**: Асинхронный HTTP клиент (System.Text.Json) с таймаутами и fire-and-forget запросами.
* **`StatsModule` / `StatsEventHandlers`**: Сбор игровой статистики (Kills, Deaths, Playtime, сессии игроков и администраторов) и отправка на веб-сервер.
* **`IBotBridge` / `IWebBridge`**: Готовые интерфейсы и DTO модели (`ServerStatusDto`, `PlayerInfoDto`, `GameEventDto`) для интеграции с Discord-ботом и панелью управления.
* **`WebhookDispatcher`**: Фоновая отправка событий раунда во внешние Discord-вебхуки.

---

### 5. 🎮 `Capy.Engine` — Игровой тулкит

* **Кастомные предметы (`CustomItem`, `CustomItemsManager`, `SpawnManager`)**:
  * Базовые классы для создания оружия, расходников и артефактов.
  * Интерфейсы `ISpawnableItem`, `IGlowingItem`, `IUsableItem`.
  * Привязка спавна к типам комнат карты (`RoomSpawnPoint`).
* **Кастомные роли (`CustomRole`, `CustomRolesManager`)**:
  * Базовый класс роли с автоматической выдачей инвентаря, патронов (`AmmoType`), Hume Shield и здоровья.
* **UI и подсказки (`PlayerDisplay`, `ShowHintExtensions`)**:
  * Высокопроизводительный батчевый рендер 20 FPS через Mirror.
  * Удобные подсказки `player.ShowCapyHint()` с авто-стэкингом.
* **Пространственное 3D-аудио (`AudioRegistry`, `AudioToggle`)**:
  * Загрузка `.ogg` файлов из `Plugins/CapyLib/Audio/`.
  * Воспроизведение 3D-звука с привязкой к игроку, объекту, комнате, схематику (`ProjectMER`) или глобально.
* **Эффекты (`ItemGlowSystem`)**:
  * Свечение и подсветка предметов на полу и в руках.
* **Серверные профили**:
  * `CapyMediumRPPlugin` — базовый класс плагина для серверов **MediumRP**.
  * `CapyNoRulesPlugin` — базовый класс плагина для серверов **NoRules**.

## 🛠️ Управление модулями (Админ-команда)

Доступна через консоль сервера или в игре администраторам (по SteamID):

| Команда | Алиас | Описание |
| :--- | :--- | :--- |
| `.capy list` | `.al l` | Список всех модулей и их статус |
| `.capy toggle <имя>` | `.al t` | Включить / выключить модуль |
| `.capy enable <имя>` | `.al on` | Включить модуль |
| `.capy disable <имя>` | `.al off` | Выключить модуль |
| `.capy restart <имя>` | `.al r` | Горячий перезапуск модуля с перечиткой конфига |
| `.capy reload` | `.al rel` | Перечитать все YAML-конфигурации с диска |

## 📦 Сборка и релизы

### Локальная сборка:
```bash
dotnet build CapyLib.csproj -c Release
```
Готовый файл: `bin/Release/net48/CapyLib.dll`.

### Релизы на GitHub:
Скомпилированные сборки публикуются в разделе [GitHub Releases](https://github.com/CapybaraPR/CapyLib/releases).
При создании любого тега `v*` воркфлоу GitHub Actions автоматически собирает и публикует свежую DLL.
