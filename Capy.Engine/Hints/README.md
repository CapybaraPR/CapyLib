# 💬 Capy.Engine.Hints — Движок подсказок и внутриигрового HUD

Модуль **Hints** предоставляет систему многослойного рендеринга подсказок (Hints) и графических элементов на экране игрока с поддержкой приоритетов, очередей, динамического форматирования RichText и плейсхолдеров.

---

## 🌟 Возможности

1. **Многослойный дисплей (`PlayerDisplay`)**:
   * Независимое отображение статических элементов HUD (например, таймер раунда, уровень, статус фракции) и динамических уведомлений (сообщения от сервера, получение урона, подсказки).
2. **Абстрактные подсказки (`AbstractHint`)**:
   * Настройка времени отображения, приоритета перекрытия, интерполяции переменных.
3. **Совместимость**:
   * Интеграция с `HintServiceMeow-Exiled` для оптимизации количества сетевых пакетов и предотвращения мерцания экрана.

---

## 💻 Пример использования

```csharp
using Capy.Engine.Hints.Service;

// Отображение подсказки с форматированием
player.ShowCustomHint(
    text: "<size=30><color=#FFA500><b>Внимание:</b></color></size>\nБоеголовка будет активирована через <b>60</b> секунд!",
    duration: 5f
);
```
