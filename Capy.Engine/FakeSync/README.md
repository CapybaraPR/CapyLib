# 🔮 Capy.Engine.FakeSync — Система сетевой иллюзии (Mirror / HLAPI)

`FakeSync` — это подсистема низкоуровневой модификации сетевого трафика Mirror Networking в SCP:SL. Она позволяет отправлять игрокам персонализированные пакеты состояния (`EntityStateMessage`, `RpcMessage`), создавая иллюзию изменений мира, ролей, предметов, объектов и освещения без изменения реального состояния сервера для остальных участников.

---

## 🚀 Основные возможности

1. **`FakeSyncVar`** — подмена синхронизируемых переменных (`[SyncVar]`):
   * Визуальное скрытие или изменение роли игрока для выбранного наблюдателя (например, маскировка под сотрудника МОГ).
   * Персонализированное здоровье, выносливость или эффекты.

2. **`FakeRpc`** — отправка прямых сетевых вызовов `ClientRpc`:
   * Воспроизведение звуков и анимаций только для одного игрока.
   * Персональные вспышки, экраны и триггеры.

3. **`FakeSyncList`** — манипуляция коллекциями `SyncList`:
   * Подмена содержимого инвентаря или навесного оборудования оружия для клиентского отображения.

4. **`AdminToyFake`** — персонализированные примитивы AdminToy:
   * Спавн стен, дверей, указателей, 3D-текста или источников света, видимых только конкретным игрокам (или администраторам).
   * Нулевая нагрузка на серверную физику — объекты существуют только на клиенте получателя.

---

## 💻 Примеры использования API

### 1. Отправка Fake SyncVar
```csharp
using Capy.Engine.FakeSync;

// Подмена роли игрока только для наблюдателя targetPlayer
targetPlayer.SendFakeSyncVar(targetIdentity, characterRoleBehaviour, writer =>
{
    writer.WriteRoleType(RoleTypeId.Scientist);
});
```

### 2. Создание персонального AdminToy примитива
```csharp
using Capy.Engine.FakeSync;

// Спавн светящейся сферы только для одного игрока
player.SendFakePrimitive(
    primitiveType: PrimitiveType.Sphere,
    position: new Vector3(0f, 10f, 0f),
    rotation: Quaternion.identity,
    scale: new Vector3(1f, 1f, 1f),
    color: Color.cyan
);
```
