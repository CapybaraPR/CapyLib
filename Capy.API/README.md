# 🌐 Capy.API — Сетевой и интеграционный слой CapyLib

`Capy.API` объединяет все внешние сетевые сервисы, HTTP API, вебхуки, системы синхронизации и сбора игровой аналитики для экосистемы **CapyLib**.

---

## 📂 Структура подсистем

| Директория | Описание |
| :--- | :--- |
| **`DiscordBridge/`** | Защищенный мост управления сервером из Discord по SSH RSA ключам, логирование, синхронизация ролей и привязка Steam/Discord. |
| **`Webhooks/`** | Отправка форматированных Discord и внешних HTTP Embed-вебхуков по игровым событиям. |
| **`Http/`** | Встроенный асинхронный HTTP/REST сервер для интеграции с веб-панелями и сайтами. |
| **`Stats/`** | Модуль сбора, агрегации и выгрузки серверной и профильной статистики игроков. |
| **`Bridges/`** | Унифицированные интерфейсы и DTO-модели для внешних систем мониторинга. |

---

## ⚡ Ключевые возможности

1. **Многосерверная архитектура**:
   Каждый инстанс игрового сервера (например, **NR** на порту `8123` и **MRP** на порту `8124`) может поднимать изолированные эндпоинты с независимыми настройками доступа.

2. **Высокая безопасность**:
   Поддержка как традиционных 32+ значных API-токенов (`X-Aspect-Key`), так и асимметричной криптографии (RSA подписи запросов по SSH-ключам с защитой от Replay-атак).

3. **Событийная модель**:
   Интеграция с EXILED-событиями и шиной `EventBus` для мгновенной трансляции убийств, банов, мутов, детонаций боеголовки и репортов в реальном времени.
